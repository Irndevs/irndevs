# Google Search Console — IRN Devs

1. Acesse https://search.google.com/search-console
2. Adicione a propriedade **https://irndevs.com**
3. Verificação por meta tag: copie o `content` e descomente no `index.html`:
   ```html
   <meta name="google-site-verification" content="SEU_CODIGO">
   ```
4. Envie o sitemap: **https://irndevs.com/sitemap.xml**
5. (Opcional) Bing: https://www.bing.com/webmasters — mesmo sitemap
