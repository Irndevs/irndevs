Terminal, usuários e permissões

A base operacional para administrar Linux com segurança: navegação, usuários, grupos, permissões e sudo.

O que você vai aprender

  • Navegar pelo sistema sem depender de interface gráfica
  • Criar usuários e grupos com privilégios mínimos
  • Ler permissões e corrigir ownership sem usar chmod 777

1. O terminal como ferramenta de operação

Administrar um servidor começa por saber onde você está, o que está executando e quem tem permissão para alterar cada recurso. A regra deste curso é simples: primeiro observe, depois altere, e sempre registre mudanças importantes.

pwd
ls -lah
whoami
id
hostnamectl

O comando id mostra os grupos efetivos do usuário. Isso é mais confiável do que assumir que um usuário tem acesso só porque o nome parece administrativo.

2. Usuários, grupos e sudo

sudo adduser deploy
sudo usermod -aG sudo deploy
getent group sudo
sudo -l -U deploy
DICA DE PRODUÇÃO Use um usuário nominal para cada pessoa ou serviço. Evite compartilhar a conta root: isso melhora auditoria e reduz o impacto de uma credencial vazada.

3. Entendendo permissões

Cada arquivo possui permissões para proprietário, grupo e outros. Leia a saída de ls -l da esquerda para a direita: tipo, usuário, grupo e bits de leitura, escrita e execução.

ls -l deploy.sh
sudo chown deploy:deploy deploy.sh
chmod 750 deploy.sh
stat deploy.sh

O modo 750 permite tudo ao proprietário, leitura e execução ao grupo e nada aos demais. Prefira isso a abrir arquivos indiscriminadamente.

ATENÇÃO Evite chmod -R 777. Ele mascara problemas de ownership e cria uma superfície de ataque desnecessária.

4. Exercício

Crie um usuário operador, um grupo app e uma pasta compartilhada que apenas o grupo possa modificar. Confirme o resultado com dois usuários diferentes e documente os comandos usados.
