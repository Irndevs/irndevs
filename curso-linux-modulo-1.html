2. Usuários, grupos e sudo

sudo adduser deploy
sudo usermod -aG sudo deploy
getent group sudo
sudo -l -U deploy
DICA DE PRODUÇÃO Use um usuário nominal para cada pessoa ou serviço. Evite compartilhar a conta root: isso melhora auditoria e reduz o impacto de uma credencial vazada.

3. Entendendo permissões

Cada arquivo possui permissões para proprietário, grupo e outros. Leia a saída de ls -l da esquerda para a direita: tipo, usuário, grupo e bits de leitura, escrita e execução.

ls -l deploy.sh
sudo chown deploy:deploy deploy.sh
chmod 750 deploy.sh
