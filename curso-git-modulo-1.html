Primeiros commits e o fluxo básico

Instale o Git, configure nome/e-mail, faça o primeiro repositório local e envie para o GitHub com segurança.

O que você vai aprender

  • Instalar Git no Windows, Linux e macOS
  • Configurar user.name e user.email
  • git init, add, commit e status sem medo
  • Criar repositório no GitHub e git remote add
  • git push e o que fazer quando der conflito simples

Por que Git importa

Git é o sistema de versões padrão da indústria. Sem ele, você não colabora em time, não mostra portfólio e não sobrevive a “apaguei o arquivo sem querer”.

Instalação rápida

# Windows: baixe em git-scm.com ou winget install Git.Git
# macOS: xcode-select --install  ou  brew install git
# Ubuntu/Debian:
sudo apt update && sudo apt install -y git
git --version

Configuração mínima (uma vez por máquina)

git config --global user.name "Seu Nome"
git config --global user.email "voce@email.com"
git config --global init.defaultBranch main

Seu primeiro repositório

mkdir meu-projeto && cd meu-projeto
git init
echo "# Meu projeto" > README.md
git add README.md
git commit -m "chore: primeiro commit"

Subir para o GitHub

  1. Crie um repositório vazio no GitHub (sem README se o local já tem)
  2. Copie a URL HTTPS ou SSH
  3. No terminal:
git remote add origin https://github.com/SEU_USER/meu-projeto.git
git push -u origin main

Comandos do dia a dia

  • git status — o que mudou
  • git diff — o detalhe da mudança
  • git log --oneline — histórico curto
  • git checkout -b feature/login — nova branch

Próximo passo natural: ler o artigo portfólio no GitHub e praticar commits por 7 dias seguidos.
