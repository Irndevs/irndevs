Projeto final: servidor Linux seguro

Una identidade, SSH, systemd, firewall, logs e backup em um runbook executável.

O que você vai aprender

  • Criar um servidor reprodutível
  • Documentar decisões e rollback
  • Executar checklist de operação e recuperação

1. Cenário do projeto

Você vai preparar um servidor Ubuntu para hospedar uma aplicação, com usuário de deploy, SSH por chave, serviço supervisionado, firewall restritivo, logs consultáveis e backup agendado.

2. Runbook de entrega

  1. Atualize o sistema e crie o usuário operacional.
  2. Instale a chave SSH e valide uma segunda sessão.
  3. Configure o serviço systemd e teste restart.
  4. Aplique UFW e Fail2ban.
  5. Configure Restic e execute restore.
  6. Registre portas, caminhos, credenciais e rollback.

3. Evidências mínimas

systemctl --failed
systemctl is-enabled irn-worker
sudo ufw status numbered
sudo fail2ban-client status sshd
restic snapshots
