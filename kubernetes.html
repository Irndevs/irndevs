Kubernetes / k3s

k3s é a escolha da IRN Devs para orquestração leve: menos overhead que um Kubernetes “cheio”, adequado a homelab, borda e workloads que precisam de API Kubernetes sem complexidade desnecessária.

Do install ao GitOps (Gitea/ArgoCD), o foco é deploy repetível e operação previsível.
