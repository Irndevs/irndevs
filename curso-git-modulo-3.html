Remoto, pull request e colaboração

Clone, fetch, pull, push seguro e o ciclo de um Pull Request no GitHub.

O que você vai aprender

  • clone vs init + remote
  • fetch, pull e push
  • Abrir e revisar um PR
  • SSH vs HTTPS
  • Evitar force push na main

1. Clonar

git clone https://github.com/SEU_USER/meu-projeto.git
cd meu-projeto
git remote -v

2. Atualizar e enviar

git pull origin main
git push -u origin feature/login

3. Pull Request

No GitHub: Compare & pull request → descreva o que mudou → Create.

BOA PRÁTICA Nunca git push --force em main.

4. Checklist de um bom PR

  • Título claro e corpo com “o quê” e “por quê”
  • Diff pequeno quando possível
  • Sem segredos no diff
