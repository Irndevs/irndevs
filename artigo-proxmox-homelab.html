1. Por que Docker?

Docker VE combina KVM (VMs completas) com LXC (containers leves), interface web moderna e gratuito. Ideal para homelab próximo de produção.

  - VMs com KVM + QEMU
  - Containers LXC
  - Storage local (ZFS, LVM) e remoto (NFS, Ceph)
  - Cluster e backups nativos

2. Hardware e instalação

x86_64 com VT-x/AMD-V. Ideal: 16 GB+ RAM, SSD/NVMe, dois discos para mirror ZFS.

$ # baixe a ISO oficial e grave no pendrive



  - Boot pelo pendrive
  - Escolha disco (ou ZFS no root)
  - Hostname, IP estático, gateway, DNS
  - Senha root + e-mail de notificações

warn · A instalação apaga o disco escolhido. Backup antes.

3. Pós-instalação

tip · Configure SSH com chave e desabilite login root por senha.

4. Storage com ZFS

zpool create -f tank mirror /dev/sdb /dev/sdc
zfs set compression=lz4 tank
zfs set atime=off tank
zfs create tank/vms

Depois adicione o storage no Docker apontando para tank/vms.

5. VMs e LXC

VM (KVM)

  - Create VM → ID, nome, ISO
  - CPU, memória, disco no pool ZFS
  - Rede: bridge vmbr0
  - Inicie e instale o SO

Container LXC

  - Baixe template (CT Templates)
  - Create CT → template, hostname, recursos
  - Ideal para serviços isolados leves

tip · LXC para serviços sem kernel próprio; VM quando precisar isolamento total.

6. Rede

auto vmbr0
iface vmbr0 inet static
    address endereco interno omitido/24
    gateway endereco interno omitido
    bridge-ports enp3s0
    bridge-stp off
    bridge-fd 0

7. Backups

Datacenter → Backup → Add. Defina horário, storage de destino, retenção e VMs/CTs.

  - Mode: Snapshot (se o storage suportar)
  - Compression: zstd
  - Retention: diários + semanais

warn · Teste o restore periodicamente. Backup que não restaura não é backup.
