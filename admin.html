como ativar admin
  1. No Supabase SQL: update profiles set is_admin = true where email = 'seu@email.com';
  2. Crie policies admin ou Edge Functions com service_role para listar todos os orders/quotes
  3. Configure Storage bucket order-files (privado) + policies
  4. Para e-mail real: conecte Resend/SendGrid via Edge Function ao inserir em notifications
