Automação e scripts

Do one-liner ao script: Bash e PowerShell para tarefas repetidas.

O que você vai aprender

  • Variáveis e echo
  • Loops simples
  • Agendar com cron / Task Scheduler (visão geral)

1. Script mínimo

# Linux — hello.sh
#!/usr/bin/env bash
set -euo pipefail
NOME="${1:-mundo}"
echo "Olá, $NOME"
date

chmod +x hello.sh
./hello.sh IRN

# Windows — hello.ps1
param([string]$Nome = "mundo")
Write-Host "Olá, $Nome"
Get-Date

# execução
powershell -File .\hello.ps1 -Nome IRN

2. Loop em arquivos

# Linux
for f in logs/*.log; do
  echo "=== $f ==="
  tail -n 5 "$f"
done

# Windows
Get-ChildItem logs\*.log | ForEach-Object {
  Write-Host "=== $($_.Name) ==="
  Get-Content $_.FullName -Tail 5
}

3. Agendar

Linux: crontab -e ou systemd timer. Windows: Task Scheduler / Register-ScheduledTask. Detalhes no artigo Cron vs Task Scheduler.

ATENÇÃO Em scripts de produção use set -euo pipefail (Bash) e $ErrorActionPreference = 'Stop' (PowerShell) para falhar cedo.
