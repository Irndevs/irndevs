Conceitos e instalação

O que é container, diferença de VM, instalar Docker no Linux e primeiros comandos sem medo.

O que você vai aprender

  • Diferença entre imagem, container e volume
  • Instalar Docker Engine no Ubuntu/Debian
  • docker run, ps, logs, exec e stop
  • Boas práticas de permissão (grupo docker)

1. Container vs máquina virtual

VM virtualiza hardware. Container compartilha o kernel do host e isola processos com namespaces e cgroups. Resultado: sobe em segundos e gasta bem menos RAM.

2. Instalação (Ubuntu 22.04+)

sudo apt update
sudo apt install ca-certificates curl -y
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo $VERSION_CODENAME) stable" | sudo tee /etc/apt/sources.list.d/docker.list
sudo apt update
sudo apt install docker-ce docker-ce-cli containerd.io docker-compose-plugin -y
sudo usermod -aG docker $USER
# faça logout/login para o grupo valer

3. Primeiros comandos

docker run --rm hello-world
docker run -d --name web -p 8080:80 nginx:alpine
docker ps
docker logs web
docker exec -it web sh
docker stop web && docker rm web
DICA Sempre prefira tags explícitas (nginx:1.27-alpine) em vez de latest em produção.
EXERCÍCIO Rode hello-world e nginx. Confirme com docker ps e acesse localhost:8080. Se permission denied, confira o grupo docker.
