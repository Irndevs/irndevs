Cron no Linux e Agendador de Tarefas no Windows

Como agendar jobs em Linux (cron/systemd timers) e no Windows (Task Scheduler), com exemplos equivalentes e armadilhas de produção.

1. Quando agendar vs. fila

Agendamento serve para tarefas periódicas previsíveis (backup, limpeza, relatório). Se o volume varia ou precisa de retry inteligente, prefira fila com worker.

2. Cron e systemd timers

crontab -e
# todo dia às 03:15
15 3 * * * /usr/local/bin/backup.sh >> /var/log/backup.log 2>&1
crontab -l

Em servidores modernos, systemd timers costumam ser melhores: logs no journal, dependências e restart controlado.

sudo systemctl enable --now backup.timer
systemctl list-timers

3. Task Scheduler

$action = New-ScheduledTaskAction -Execute "powershell.exe" -Argument "-File C:\scripts\backup.ps1"
$trigger = New-ScheduledTaskTrigger -Daily -At 3:15am
Register-ScheduledTask -TaskName "BackupDiario" -Action $action -Trigger $trigger -User "SYSTEM"

GUI: taskschd.msc. Prefira conta de serviço com menor privilégio e log em arquivo ou Event Viewer.

4. Equivalências lado a lado

  • Listar jobs: crontab -l / Get-ScheduledTask
  • Logs: journalctl -u backup.service / Event Viewer → Task Scheduler
  • Rodar agora: systemctl start backup.service / Start-ScheduledTask -TaskName BackupDiario
DICA Sempre redirecione stdout/stderr para log com rotação. Job silencioso que falha é incidente atrasado.

5. Checklist de produção

  • Horário em UTC documentado
  • Usuário dedicado, sem senha interativa
  • Log + alerta se o job não rodou
  • Teste manual do script antes de agendar
