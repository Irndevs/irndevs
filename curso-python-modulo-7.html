Agendamento e deploy com cron e Docker

Coloque o robô para rodar 24 horas por dia, sem depender do seu computador ligado.

O que você vai aprender

  • Agendar execuções com cron e systemd timers
  • Empacotar uma automação Python em um Dockerfile
  • Configurar logs para acompanhar a execução do container

Código da aula

# Dockerfile — empacota o scraper agendado
FROM python:3.12-slim

WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY scraper_cotacoes.py .

# crontab: roda a cada hora e registra log
RUN echo "0 * * * * python /app/scraper_cotacoes.py >> /var/log/cron.log 2>&1" > /etc/cron.d/scraper
RUN chmod 0644 /etc/cron.d/scraper && crontab /etc/cron.d/scraper

CMD ["cron", "-f"]
