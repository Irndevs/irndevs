Projeto final: app + proxy

API containerizada atrás de Nginx, com volume, healthcheck e restart — pronta para VPS.

O que você vai aprender

  • Compose com api + nginx
  • Reverse proxy e headers
  • Deploy em VPS com docker compose
  • Checklist de produção

Arquitetura

services:
  api:
    build: ./api
    expose: ["8000"]
    env_file: .env
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8000/health"]
      interval: 30s
    restart: unless-stopped
  proxy:
    image: nginx:1.27-alpine
    ports: ["80:80"]
    volumes:
      - ./nginx.conf:/etc/nginx/conf.d/default.conf:ro
    depends_on:
      api:
        condition: service_healthy
    restart: unless-stopped

Checklist de entrega

  • Imagens com tags fixas
  • Non-root + .env fora do git
  • Healthcheck e restart
  • Logs rotativos
  • README com docker compose up -d
