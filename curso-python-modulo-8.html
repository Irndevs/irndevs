Projeto final: robô completo em produção

Uma pipeline completa, do zero à produção: coleta de dados, processamento e envio de relatório, com logs e tratamento de erro de verdade.

O que você vai aprender

  • Estruturar um projeto de automação com arquitetura clara e reutilizável
  • Tratar erros e falhas sem derrubar a automação inteira
  • Registrar logs e monitorar a execução da pipeline em produção

Código da aula

# pipeline.py — coleta, processa e envia relatório, com logging
import logging

from scraper_cotacoes import coletar_cotacoes, salvar_csv
from email_relatorio import enviar_relatorio

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s [%(levelname)s] %(message)s",
    filename="pipeline.log",
)

def rodar_pipeline():
    try:
        logging.info("Iniciando coleta de dados")
        dados = coletar_cotacoes()

        logging.info("Salvando dados coletados")
        salvar_csv(dados, "cotacoes.csv")

        logging.info("Enviando relatório por e-mail")
        enviar_relatorio("time@empresa.com", "cotacoes.csv")

        logging.info("Pipeline concluída com sucesso")
    except Exception as erro:
        logging.error(f"Falha na pipeline: {erro}")
        raise

if __name__ == "__main__":
    rodar_pipeline()
