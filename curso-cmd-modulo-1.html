Navegação e arquivos

Onde estou, listar, copiar, mover e editar — os mesmos gestos no Bash e no PowerShell.

O que você vai aprender

  • Ver diretório atual e listar conteúdo
  • Criar, copiar, mover e apagar arquivos
  • Diferenças de caminho (barra vs barra invertida)
  • Editar texto rápido no terminal

1. Onde estou e o que tem aqui

AçãoLinux (Bash)Windows (PowerShell)
Diretório atualpwdpwd ou Get-Location
Listarls -lahls ou Get-ChildItem
Mudar pastacd /var/logcd C:\Windows\Logs
Criar pastamkdir -p apps/logsmkdir apps\logs
 
# Linux
pwd
ls -lah
cd ~
mkdir -p projetos/demo
touch projetos/demo/README.md

# Windows PowerShell
pwd
Get-ChildItem
cd $HOME
mkdir projetos\demo
New-Item projetos\demo\README.md -ItemType File

2. Copiar, mover, apagar

AçãoLinuxWindows
Copiar arquivocp a.txt b.txtCopy-Item a.txt b.txt
Copiar pastacp -r src/ dst/Copy-Item src dst -Recurse
Mover/renomearmv old.txt new.txtMove-Item old.txt new.txt
Apagarrm -rf pasta/Remove-Item pasta -Recurse -Force
ATENÇÃO rm -rf e Remove-Item -Recurse -Force não pedem confirmação. Teste em pasta de rascunho.

3. Ver e editar conteúdo

# Linux
cat arquivo.txt
less arquivo.txt
nano arquivo.txt   # ou vim

# Windows
Get-Content arquivo.txt
Get-Content arquivo.txt -TotalCount 20
notepad arquivo.txt
DICA No PowerShell muitos aliases existem (ls, cd, cat). Em scripts longos, prefira os cmdlets completos (Get-ChildItem) para clareza.
