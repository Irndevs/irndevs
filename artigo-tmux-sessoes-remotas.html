Tmux: sessões que sobrevivem à queda de SSH

Como usar tmux para não perder trabalho quando a conexão cai — painéis, sessões nomeadas e fluxo mínimo para servidores.

1. Por que tmux

SSH cai. Comando longo morre junto. Tmux mantém a sessão no servidor: você reconecta e continua de onde parou.

2. Sessões e atalhos

tmux new -s deploy
tmux ls
tmux attach -t deploy
# prefix: Ctrl+b
# Ctrl+b d  → detach
# Ctrl+b c  → nova janela
# Ctrl+b %  → split vertical

3. Fluxo em produção

ssh user@servidor
tmux attach -t ops || tmux new -s ops
# trabalho...
# Ctrl+b d
DICA Uma sessão por contexto (ops, logs, db) evita bagunça.

4. E no Windows?

Em servidores Windows, prefira serviços ou o Agendador para jobs longos. Para trabalho interativo remoto, SSH + tmux em um host Linux intermediário continua sendo o caminho mais estável.

5. Checklist

  • Sessão nomeada por tarefa
  • Detach antes de fechar o terminal local
  • Não rodar como root sem necessidade
