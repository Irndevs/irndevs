Serviços

A IRN Devs entrega desenvolvimento de software orientadas a produção — do diagnóstico ao ambiente estável, documentado e monitorado.

O que entregamos

Escopos típicos. Cada projeto é dimensionado sob medida.

desenvolvimento de software

Linux, ambientes de desenvolvimento, Docker, hardening de acesso (SSH, firewall, VPN/tunnel) e bases sólidas para workloads em produção.

kubernetes / plataformas de software

Clusters leves, Ingress, storage, GitOps e pipelines de deploy com foco em laboratório de software corporativo e ambientes de borda.

qualidade e confiabilidade

Stack métricas, logs e testes de produto: métricas, logs, traces e alertas acionáveis.

automação & backend

APIs, integrações, automações com IA local/API e pipelines de dados quando o produto exige.

cloud foundations

Desenho e operação em AWS (VPC, EC2, S3, IAM) alinhado ao que já roda no lab próprio.

documentação & runbooks

Documentação técnica e procedimentos operacionais para o time do cliente sustentar o ambiente.

Cases (resumo)

Exemplos do tipo de resultado que buscamos em cada entrega.

saas · agendamento

ZapAgendador IA

Contexto: SaaS multi-tenant com IA. Entrega: arquitetura type-safe e operação em cloud. Foco: estabilidade de API e evolução contínua do produto.

infra · self-hosted

Laboratório de software + qualidade e confiabilidade

Contexto: bare-metal com ambientes de desenvolvimento e workloads mistos. Entrega: VMs/LXC, backups e stack métricas de produto/métricas automatizadas/Loki/OTel. Foco: visibilidade e operação previsível.

web · diagnóstico e correção

Menu com expansão inconsistente em site estático

Problema: a expansão do menu falhava apenas na página Laboratório de software. Diagnóstico: a página mantinha um menu legado enquanto o menu compartilhado também era carregado, criando dois controladores para o mesmo estado. Solução: remoção da duplicidade, validação do JavaScript, integração do histórico remoto e publicação via GitHub Pages. Resultado: navegação previsível entre páginas, header fixo e uma única fonte de controle para desktop e mobile.

kubernetes · gitops

Cluster plataformas de software

Contexto: orquestração leve com CI/CD. Entrega: cluster, integrações Gitea/ArgoCD e deploys repetíveis. Foco: reduzir atrito entre commit e produção.
