APIs e webhooks com FastAPI

Transforme suas automações em serviços de verdade, prontos para serem chamados por outros sistemas.

O que você vai aprender

  • Criar rotas e validar dados de entrada com pydantic
  • Expor uma automação como endpoint HTTP
  • Receber e processar webhooks disparados por sistemas externos

Código da aula

# api_automacao.py — endpoint que dispara uma automação
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class PedidoAutomacao(BaseModel):
    email: str
    relatorio: str

@app.post("/disparar")
def disparar_automacao(pedido: PedidoAutomacao):
    # aqui entraria a chamada para a automação real (ex: módulo 5)
    return {
        "status": "recebido",
        "email": pedido.email,
        "relatorio": pedido.relatorio,
    }

@app.post("/webhook/pagamento")
def webhook_pagamento(payload: dict):
    evento = payload.get("evento")
    if evento == "pagamento_confirmado":
        # dispara alguma automação em resposta ao evento
        pass
    return {"recebido": True}
