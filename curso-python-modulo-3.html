Automação de navegador com Selenium e Playwright

Faça o navegador clicar, preencher formulários e baixar arquivos por você, como se um humano estivesse na frente da tela.

O que você vai aprender

  • Configurar drivers de navegador e entender a diferença entre Selenium e Playwright
  • Usar esperas explícitas para lidar com páginas que carregam conteúdo dinâmico
  • Tirar screenshots automáticos e trabalhar com Playwright no modo assíncrono

Código da aula

# login_download.py — login automático e download de relatório
import asyncio
from playwright.async_api import async_playwright

async def baixar_relatorio():
    async with async_playwright() as p:
        navegador = await p.chromium.launch(headless=True)
        pagina = await navegador.new_page()

        await pagina.goto("https://exemplo-portal.com/login")
        await pagina.fill("#usuario", "meu_usuario")
        await pagina.fill("#senha", "minha_senha")
        await pagina.click("button[type=submit]")

        await pagina.wait_for_selector("#dashboard")
        await pagina.screenshot(path="dashboard.png")

        async with pagina.expect_download() as download_info:
            await pagina.click("text=Baixar relatório")
        download = await download_info.value
        await download.save_as("relatorio.xlsx")

        await navegador.close()
        print("Relatório baixado com sucesso.")

if __name__ == "__main__":
    asyncio.run(baixar_relatorio())
