Processos e serviços

Ver o que está rodando, matar processo com segurança e controlar serviços nos dois sistemas.

O que você vai aprender

  • Listar processos e uso de CPU/RAM
  • Encerrar processo com segurança
  • Status, start e stop de serviços

1. Processos

AçãoLinuxWindows
Listarps aux / topGet-Process
Buscar por nomepgrep -a nginxGet-Process nginx*
Matar por PIDkill 1234Stop-Process -Id 1234
Matar por nomepkill -f "node app"Stop-Process -Name node -Force
 
# Linux — top interativo, q para sair
top
htop   # se instalado

# Windows
Get-Process | Sort-Object CPU -Descending | Select-Object -First 10
Get-Process | Sort-Object WorkingSet -Descending | Select -First 10

2. Serviços

# Linux (systemd)
systemctl status nginx
sudo systemctl start nginx
sudo systemctl stop nginx
sudo systemctl restart nginx
sudo systemctl enable nginx   # inicia no boot

# Windows
Get-Service -Name wuauserv
Start-Service -Name wuauserv
Stop-Service -Name wuauserv
Restart-Service -Name wuauserv
Set-Service -Name wuauserv -StartupType Automatic
PRODUÇÃO Prefira restart controlado do serviço a matar processo na força. Mate processo só quando o serviço não responde.
