JavaScript é a linguagem da web

Roda no navegador de graça, sem instalar runtime extra. É a ponte entre HTML estático e interfaces que reagem ao usuário.

Base da linguagem

const nome = "Ana";
let contador = 0;
const ativo = true;

function saudacao(pessoa) {
  return `Olá, ${pessoa}!`;
}

if (contador === 0) {
  console.log(saudacao(nome));
}

Interagindo com a página

// HTML: <button id="btn">Clique</button>
const btn = document.querySelector("#btn");
btn.addEventListener("click", () => {
  btn.textContent = "Clicado!";
});
