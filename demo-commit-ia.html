Gerador de commits inteligentes MOTOR LOCAL

Cole o git diff (ou um trecho). Motor local reforçado: tipo, escopo, breaking change, corpo com arquivos e stats. Tudo no browser. Para qualidade de LLM, use o prompt.

cole um diff e clique em gerar commit
como funciona · Esta demo usa heurísticas locais (tipo de arquivo, palavras-chave no diff, adições/remoções). Não chama API nenhuma — o código não sai do seu browser. Para mensagens mais precisas, use “copiar prompt para IA” e cole no ChatGPT, Claude ou Cursor.
