Rede e diagnóstico

IP, DNS, portas abertas e teste de conectividade — os comandos que resolvem 80% dos “a rede caiu”.

O que você vai aprender

  • Ver IP e rotas
  • Testar DNS e conectividade
  • Ver quem escuta em qual porta

1. Endereço e interface

AçãoLinuxWindows
IPsip aipconfig / Get-NetIPAddress
Rotasip rroute print / Get-NetRoute
DNSresolvectl statusGet-DnsClientServerAddress

2. Conectividade

# Linux
ping -c 4 1.1.1.1
curl -I https://example.com
dig example.com
ss -lntp          # portas em escuta
traceroute 1.1.1.1

# Windows
ping 1.1.1.1
Test-NetConnection example.com -Port 443
Resolve-DnsName example.com
netstat -ano | findstr LISTENING
tracert 1.1.1.1

3. Porta em uso

# Linux — quem usa a 443
sudo ss -lntp | grep :443
sudo lsof -i :443

# Windows
netstat -ano | findstr :443
Get-NetTCPConnection -LocalPort 443
ATENÇÃO Em produção, ping pode estar bloqueado por firewall. Prefira testar a porta real do serviço (443, 22, etc.).
