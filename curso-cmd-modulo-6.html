Projeto final

Escolha um sistema e faça:

  1. Criar pasta ops-lab com 3 arquivos de log fictícios
  2. Script que imprime as 5 últimas linhas de cada log
  3. Listar processos que mais usam CPU
  4. Mostrar se a porta 443 está em escuta

Depois repita no outro sistema. O objetivo não é memorizar tudo: é saber onde olhar e traduzir o comando.
