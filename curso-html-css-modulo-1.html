Estrutura HTML e o primeiro CSS

Monte uma página estática válida, com tipografia legível, links e um layout simples sem framework.

O que você vai aprender

  • Estrutura mínima de um documento HTML5
  • Tags semânticas: header, main, section, footer
  • CSS: seletores, cores, espaçamento e fonte
  • Links, imagens e acessibilidade básica
  • Publicar mentalmente: o que é estático vs dinâmico

HTML não é programação — e tudo bem

HTML descreve estrutura. CSS descreve aparência. Juntos formam a base de qualquer interface web. Frameworks vêm depois.

Documento mínimo

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Minha página</title>
  <link rel="stylesheet" href="estilo.css">
</head>
<body>
  <header><h1>Olá</h1></header>
  <main>
    <p>Meu primeiro conteúdo.</p>
  </main>
</body>
</html>

CSS enxuto que já melhora tudo

body {
  font-family: system-ui, sans-serif;
  line-height: 1.6;
  max-width: 40rem;
  margin: 2rem auto;
  padding: 0 1rem;
  color: #1a1a1a;
}
a { color: #0b57d0; }

Exercício

Crie uma página “Sobre mim” com: nome, 1 parágrafo, lista de 3 skills e um link para o GitHub. Valide mentalmente: título único, um h1, contraste legível.

Depois avance para JavaScript para deixar a página interativa.
