SELECT, WHERE e suas primeiras consultas

Aprenda a ler e filtrar dados em banco relacional com SQL real — a skill que backend, dados e analytics pedem o tempo todo.

O que você vai aprender

  • O que é tabela, linha, coluna e chave primária
  • SELECT e projeção de colunas
  • WHERE, AND/OR e operadores de comparação
  • ORDER BY e LIMIT
  • Boas práticas para não travar o banco

Por que SQL continua insubstituível

Planilhas não escalam. ORMs ajudam, mas quando o relatório trava ou a API fica lenta, alguém escreve SQL. Aprender o básico te coloca à frente da maioria dos iniciantes.

Consultas essenciais

-- todas as colunas (use com cuidado em tabelas grandes)
SELECT * FROM clientes;

-- só o necessário
SELECT id, nome, email FROM clientes WHERE ativo = true;

-- ordenar e limitar
SELECT nome, criado_em
FROM clientes
ORDER BY criado_em DESC
LIMIT 20;

Filtros que você vai usar sempre

WHERE preco >= 100
WHERE nome ILIKE '%silva%'   -- Postgres
WHERE email IS NOT NULL
WHERE status IN ('pago', 'enviado')

Cuidado com SELECT *

Em produção, prefira listar colunas. Isso reduz tráfego, deixa a intenção clara e evita quebrar clientes quando a tabela ganha colunas novas.

Ambiente para praticar: SQLite local, ou um Postgres em Docker. O curso de Docker ajuda a subir um banco em minutos.
