Planilhas e dados com pandas e openpyxl

Chega de planilha manual: consolide dezenas de arquivos em um único relatório em poucos segundos.

O que você vai aprender

  • Ler e combinar múltiplos arquivos com DataFrame e merge
  • Agrupar e resumir dados com groupby
  • Exportar relatórios formatados para Excel com openpyxl

Código da aula

# consolida_relatorios.py — junta 12 planilhas mensais em 1 relatório
from pathlib import Path
import pandas as pd

pasta = Path("relatorios_mensais")
arquivos = sorted(pasta.glob("*.xlsx"))

tabelas = [pd.read_excel(arquivo) for arquivo in arquivos]
dados = pd.concat(tabelas, ignore_index=True)

resumo = (
    dados.groupby("categoria")["valor"]
    .sum()
    .reset_index()
    .sort_values("valor", ascending=False)
)

with pd.ExcelWriter("relatorio_consolidado.xlsx", engine="openpyxl") as escritor:
    dados.to_excel(escritor, sheet_name="Dados brutos", index=False)
    resumo.to_excel(escritor, sheet_name="Resumo por categoria", index=False)

print(f"{len(arquivos)} arquivos consolidados em relatorio_consolidado.xlsx")
